Privacy Policy

Last updated: 2026-11-17

1. Who we are

antares-biblia ("the tool") is operated by Rodrigo Calé Pereira Lopes, an individual, for the sole purpose of managing the owner's own YouTube channel. Contact: rodrigocalemkt2@gmail.com.

2. YouTube API Services

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to data handled through these services: https://policies.google.com/privacy.

3. Data accessed

Through OAuth 2.0, and only with the authorization of the channel owner, the tool accesses: the owner's channel information, the owner's own videos and their metadata, and the owner's own channel analytics. It requests these scopes: youtube.upload, youtube.readonly, yt-analytics.readonly and youtube.force-ssl.

4. Use of data

The data is used only to upload and schedule the owner's videos, update their metadata and thumbnails, and generate reports that guide the owner's content planning. It is not used for advertising, is not sold, shared or transferred to third parties, and is not used to build profiles of other people.

5. Storage

Credentials (the OAuth refresh token) and API responses are stored only on the owner's own computer, in a local folder protected from version control. No data is sent to any server operated by the tool. Analytics and metadata are retained locally only while needed for planning and are deleted on request or when the owner revokes access.

6. Other users' data

The tool does not collect personal data of viewers or other users beyond what is included in the owner's own channel metrics.

7. Revoking access and deleting data

You can revoke the tool's access to your Google account at any time at https://myaccount.google.com/permissions. After revocation, the stored token is invalid and the local credential files are deleted. To request deletion of any stored data, write to rodrigocalemkt2@gmail.com; requests are handled within 30 days.

8. Changes

This policy may be updated; the date above shows the latest version.
